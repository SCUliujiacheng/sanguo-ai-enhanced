# 三国群英传 AI 加强版

为喜欢《三国群英传》的玩家制作的非官方同人修改版：修复出征携款问题，改进电脑出兵判断，并扩展可选时期与挑战开局。保留原有自动战斗功能。

**下载游戏：前往 [Releases](https://github.com/SCUliujiacheng/sanguo-ai-enhanced/releases)，在对应版本的 Assets 中下载 `.apk` 文件。** GitHub 自动生成的 Source code 压缩包不是安装包。

## 主要变化

- **资金转移守恒**：部队从城市带走金钱时，出发城市扣除同样金额；携款不超过城市余额。
- **电脑更重视胜算**：统计全部守将，综合战力与人数选择部队，集结援军并保留守军；出兵前和抵达敌城时重新判断局势。
- **更多开局**：在原有 5 个时期之外，新增 7 个历史时期与 2 个架空挑战，共 14 个剧本。
- **历史搜将**：历史模式按登场年份、活动地区和当时阵营筛选人才；原属势力灭亡后，允许当地占领者招募。玩家与电脑共用规则，两个架空挑战保留自由搜索。详见[搜将规则与史料边界](docs/RECRUITMENT.md)。

AI 改动采用规则判断，没有给电脑额外金钱或直接提高武将面板属性。实际战斗结果仍受武将技能、兵力和操作影响。

## 安装与更新

1. 从本仓库 Releases 下载想要安装的版本，并核对发布说明中的文件名。
2. 有重要存档时，先确认已完成可恢复的备份，再安装或更新。
3. 在 Android 手机上打开 APK，按照系统提示安装。
4. 安装失败或出现签名冲突时，先查看[安装与存档说明](docs/INSTALL.md)，不要直接卸载有重要存档的旧版。

1.2.0 沿用上一“经济修复与 AI 优化”修改版的签名和包名，可尝试直接覆盖更新并保留数据；请先保护重要存档。与来源 APK 的签名不同，不能直接覆盖来源版。

## 反馈问题与建议

请通过 [Issues](https://github.com/SCUliujiacheng/sanguo-ai-enhanced/issues)反馈。尽量提供 APK 文件名或版本、手机型号与 Android 版本、剧本与势力、复现步骤、预期结果和实际结果。涉及存档时先保留原件；上传截图或附件前请移除个人信息。
