# 功能图解

[返回首页](../README.md) · [下载游戏](https://github.com/SCUliujiacheng/sanguo-ai-enhanced/releases/tag/v1.3.0) · [安装与存档](INSTALL.md)

自动内政、自动战斗和装备自动分配，都是加强版相对原版的扩展功能。**v1.3.0 保留这三项功能并重新调整战斗规则**，详情见[三兵种、升迁、智力冷却与协同攻城](GAMEPLAY-v1.3.0.md)。本页配图由玩家提供，红框和箭头保留图片中的原有标注。

## 自动内政：选好顺序，一键安排

进入内政界面，点击 **总内政**，再选择“搜筑开”等优先顺序，即可批量尝试招降俘虏，并安排搜索、筑城和开发。把重复指派交给游戏，腾出时间考虑下一步扩张。

<p align="center">
  <img src="media/auto-affairs.png" alt="自动内政界面，可选择搜筑开、搜开筑等六种优先顺序" width="720">
</p>

“搜”是搜索，“筑”是筑城，“开”是开发。例如“搜筑开”先安排符合搜索条件的武将，再由仍可行动的武将依次执行筑城和开发。每次点击执行一轮安排，下一次内政仍可重新选择优先顺序。

| 任务 | 自动安排条件 |
| --- | --- |
| 搜索 | 武力或智力达到 85 |
| 筑城 | 武力达到 80 |
| 开发 | 智力达到 80 |

以上任务使用在城、未被俘且本轮仍可行动的己方非君主武将。招降与搜索有成功概率；历史剧本的自动搜索同样遵循[年份、地区与阵营规则](RECRUITMENT.md)。

## 自动战斗：一场对决，或整场交战

在战前选将界面，**单次自动**结算当前双方武将的对决；**全体自动**经确认后连续处理对决，直到本场交战结束。仍可使用原有“出战”入口进行手动战斗。

<p align="center">
  <img src="media/auto-battle.png" alt="战前选将界面，箭头标出单次自动与全体自动按钮" width="720">
</p>

自动结算会考虑当前武将状态、兵力、兵种、可用技能和守城条件，并写回体力、技力与兵力消耗。它使用数值模拟快速结算，结果可能与手动战斗不同；强弱对比和战损仍然需要纳入出兵决策。

## 装备自动分配：全势力一起整理

进入内政中的 **物品使用** 界面，点击左下角 **自动分配** 并确认。游戏会统筹各城库存与己方武将现有装备，根据装备加成及武将属性重新分配，并安排兵种、阵法学习物品。

<p align="center">
  <img src="media/auto-equipment.png" alt="物品使用界面，箭头标出左下角的自动分配按钮" width="720">
</p>

分配范围覆盖整个己方势力的非俘虏武将，包括君主；已穿戴的装备也会参与调整。每名武将仍只有一个装备槽，坐骑分给剩余空位，学习物品分给尚未掌握对应兵种或阵法的武将，剩余物品留在库存。想保留某位武将的指定装备时，可在自动分配后手动调整。

## 多时期：换一个开局，换一场博弈

v1.2.0 在原有 5 个时期之外增加 **7 个历史开局与 2 个架空挑战**，共 14 个剧本。时期菜单通过 **上一页 / 下一页** 切换，既能重走官渡、汉中等历史节点，也能体验英雄集结与孤城逆袭。

<p align="center">
  <img src="media/scenarios.jpg" alt="时期选择第二页，展示官渡争锋、三顾茅庐、潼关风云、入主巴蜀和汉中争夺" width="720">
</p>

历史搜将依据登场年份、活动地区与当时阵营筛选人才。历史归属势力灭亡后，当地占领者可以招募；已经归队或被俘的武将继续遵循实际游戏归属。两个架空挑战保留自由搜索，详见[历史搜将说明](RECRUITMENT.md)。
