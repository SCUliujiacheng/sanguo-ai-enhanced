# v1.5.0 · 智力决定技能充能

**技能充能只看智力**。武力再高，也不会代替智力加快技能条；武力继续影响普通攻击。手动战斗、玩家自动与电脑自动结算共用新规则。

## 更清楚的施法分工

智力越高，充能越快；充能速率按对数曲线上升，高端增益逐渐减小。取消旧“武力、智力取较高值”的基础速率，也不再叠加“智力超过 60 额外减冷却”。

| 智力 | 开场充满约需 | 施法后重新充满约需 |
| ---: | ---: | ---: |
| 20 | 24.2 秒 | 44.3 秒 |
| 30 | 17.4 秒 | 31.9 秒 |
| 40 | 13.7 秒 | 25.2 秒 |
| 60 | 9.8 秒 | 18.0 秒 |
| 80 | 7.8 秒 | 14.3 秒 |
| 100 | 6.5 秒 | 12.0 秒 |
| 120 | 5.7 秒 | 10.4 秒 |

开场仍自带 60 / 132 充能；第一次只需再充 72，后续重新充满 132。以上为理论充能时间，未计暂停、技能动画或施法操作；手动帧率与自动 0.1 秒量化存在微小差异。智力 100 的速率约为智力 30 的 **2.67 倍**。

## 技力仍然决定能放几次

更快充能意味着更早获得施法机会。每次仍按原技能消耗技力，没有新增回蓝；技力不足或没有符合条件的技能时不能施放。因此并非所有高智力将每场都会放出更多次技能。

例：51 技力、每次消耗 22 的炎龙，仍最多施放两次。高智力将能更早准备好第二次技能，低智力将需要等待更久。

## 旧档与此前修复

不改存档结构；读取现有智力与装备后的有效属性。负智力按 0 处理，120 以上按 120 处理，保留正的基础速率，避免旧档异常值导致除零或无限加速。智力 0 的完整充能约 264 秒，在通常 99 秒战斗中可能来不及施法。

保留 [v1.4.2 技能条显示修复](GAMEPLAY-v1.4.2.md)、[v1.4.1 自动结算与和局修复](GAMEPLAY-v1.4.1.md)，以及三兵种、自动内政、装备分配和多时期等[既有功能](FEATURES.md)。
