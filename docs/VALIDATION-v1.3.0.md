## 战斗抽样

同等配置的 1,000 个固定种子中，左侧胜率 49.4%。同等配置下三项克制方向的优势方胜率分别为 98.8%、94.4%、83.6%；三倍兵力能在对应用例中克服逆克制。专用施法用例中，智力 30 与 100 分别施法 3 次与 8 次。

这些是回归用例数据，不能解释为所有武将、所有兵力和技能组合的实际胜率。弓箭射程、主将武力和技能仍会改变对局；后续平衡可以根据实玩反馈继续调整。
