# v1.6.0 战略攻防与难度版

**新游戏 → 选择时期 → 选择难度 → 选择君主。** 三档难度调整电脑武将每月恢复的体力、技力，以及城市每年收到的税金。以同属性武将、同人口城市的玩家收益为基准。

| 难度 | 玩家 | 电脑 |
| --- | ---: | ---: |
| 简单 | 100% | 80% |
| 普通 | 100% | 100% |
| 困难 | 100% | 120% |

难度和未满一点的恢复、收入余量随各自存档保存。旧档读作普通。战斗中的技能条继续按智力充能。

**电脑出兵。** 电脑在原有月末规划之外，月中也会寻找战机。主力正在集结或行军时，另一条战线若有能独立取胜的部队，也可出击。

**重镇失守后的回援。** 战略地图每推进一个行军时段，电脑会先检查正在逼近的敌军，再查看因为城池易手而暴露的新边境。可通过最多五段己方道路调遣后方援军。危急时，另一处边境也可以从守备有余的兵力中抽调。守军与在途援军合计计算，援兵实际沿地图行军。

**后方自动运金。** 玩家城市的预备兵达到上限、与敌城不接壤时，剩余金钱经连通的己方城池自动转入君主驻城。征满最后一名预备兵的费用先扣。君主出征或被俘时暂停。有敌军正逼近的城池会避开，仍有安全路线便可绕行。君主在前线驻守也能收款。单城最多存 999999，放不下的钱留在来源城。

在 14 张地图上各选两个玩家势力、每组用八个配对种子测试首月出兵。两版合计各跑 224 个开局。电脑向所有敌城出兵合计由 632 队增至 840 队，其中专门进攻玩家的首月总数两版均为 248 队，新版有 224 队提前到月中出发。另设同一玩家边城持续可攻、每次出兵后完整返回的对照，六个月内出兵由 6 次增至 12 次。这些数字衡量决策时机，实际抵达时间、伤亡和胜负取决于战局。

APK 使用此前修改版签名，系统应用详情应显示 **1.6.0**（版本代码 8）。本次已检查最终安装包、难度按钮布局、旧档读取、恢复与运金、进攻与回援。安卓手机实玩仍待验证。
