# 历史搜将规则

历史模式覆盖原有五个时期和新增七个历史时期。玩家主动搜索与电脑自动搜索共用规则。

1. **按年份登场**：人才进入规则规定的年份区间后，才会进入搜索候选。没有到登场年份、已经超过该条目的退场年份，或只存在于演义中的人物，不会作为历史模式的新人才被搜出。
2. **在活动地区搜索**：搜索发生的城池必须属于该人物当前阶段的活动地区。历史地名会映射到原游戏现有的 48 座城池，区域有时包含相邻数城，不代表精确到城的历史考证。
3. **遵循当时归属**：历史归属势力仍存续时，由该势力在合适地区搜索。同一阵营的后继君主也可列为允许归属。
4. **势力灭亡后的机会**：规则列出的历史归属势力全部灭亡后，占领该活动地区的势力可以搜索此人。年份和地区条件仍然有效。
5. **保留战局造成的变化**：规则仅筛选尚未归队、没有被俘的人才。已经归队或被俘的武将继续按游戏进行，不会因进入某一年而强制转投、消失或死亡。

“英雄集结”和“孤城逆袭”属于架空挑战，保留自由搜索，不使用历史年份、活动地区和阵营限制。搜索仍有原游戏的发现与应答概率；符合条件不表示必定搜到。

## 史料与游戏设定的边界

规则表对全部 255 名原有武将逐一给出条目，并保存证据类别和说明。可考人物采用史料时序覆盖；史料不足的条目采用原剧本推定，明确标出“剧本推定”，不把推定年份包装成史实。部分演义角色可能仍在原作或新增开局的既有阵容中，搜索规则不会自动删除这些既有武将。

游戏仅按整年判断，无法还原同一年内的任职先后。跨阵营节点因此可能采用年初或次年生效的游戏约定，具体见各条目说明。新历史开局与搜将机制都是历史题材的玩法设计，并非完整历史模拟。

希望纠正条目时，请在 Issues 中提供人物、剧本年份、预期活动地区和可核对的史料出处。
