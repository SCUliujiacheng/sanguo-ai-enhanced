# 安装、更新与存档

## 找到正确的安装包

打开[版本下载页](https://github.com/SCUliujiacheng/sanguo-ai-enhanced/releases)，选择版本，在 Assets 中下载 `.apk`。Source code 的 ZIP / TAR 文件是仓库文件快照，无法作为 Android 安装包使用。

手机上可能同时保留多个下载过的 APK。安装前核对完整文件名与 Release 版本，避免误装较早版本。如果发布页提供 SHA-256，可用本地文件校验工具核对下载文件。

## 安装前先保护存档

**不要为了处理安装失败而直接卸载有重要存档的旧版。** 卸载可能删除应用数据与存档；下载 APK 不等于备份游戏进度。

本项目修改版与来源 APK 的签名不同；安装包名称不同也不代表可以作为两个独立应用并存。游戏包名沿用 `com.castle6.sanguo.sangx`，遇到签名冲突时系统可能拒绝覆盖安装。

本项目后续更新应复用修改版的签名身份。即便签名一致，也请先备份，再尝试覆盖更新。是否支持当前版本之间的更新、是否做过读档实测，请查看对应 Release 的说明；不要将“包名相同”理解为保证可迁移。

## 存档包含什么

从游戏的保存逻辑确认，存档分为两部分：

- 游戏持久化数据目录下的 `SAVES/SANGO01.SAV.xml` 至 `SANGO08.SAV.xml`。
- Unity PlayerPrefs 中对应槽位的标志、势力、年份及其他摘要信息。

因此，单独复制 XML 文件不一定能让游戏识别存档槽位。Android 上数据目录的实际位置和可访问性取决于设备与系统版本，本项目不提供尚未在该设备验证过的通用迁移保证。

若设备或游戏已有可靠的完整备份与恢复功能，先使用它保存当前数据并确认备份可读取。无法确认备份是否完整时，保留旧安装和原数据，先在其他设备或独立测试环境体验新版。

## 进入新增剧本

新增时期用于开始新游戏。请先保存正在进行的战局，再从新游戏的时期选择页面进入。已有存档不会自动变成其他历史时期。

旧档兼容性、时期菜单的具体操作和设备运行结果，以该版 Release 的实际验证记录为准。

## 安装失败时如何反馈

请记录以下信息后在 [Issues](https://github.com/SCUliujiacheng/sanguo-ai-enhanced/issues)提交问题：

- 下载的 APK 完整文件名、Release 版本。
- 手机型号、Android 版本、是否使用模拟器。
- 原来安装的是来源版、本项目上一版，还是首次安装。
- 系统的完整错误提示或截图。

请勿公开签名私钥、账号密码或未经检查的完整设备日志。截图中若包含个人信息，先遮盖再上传。
