# v1.4.1 · 自动战斗结算修复

## 技能不会因为进入方式而失效

旧版的技能表只在进入手动战场时加载。从启动游戏直接使用自动战斗，可能没有读到已学习的技能；先打过手动战斗再使用自动结算，则能读到技能。这会让同一配置出现不同结果，尤其影响依靠技能的智将。

新版在读取技能资料时先确保配置已加载。玩家单次自动、全体自动和电脑交战使用相同技能资料；原技能消耗、效果与智力冷却规则继续保留。

## 99 秒双方存活，按和局处理

旧版在模拟到 99 秒后比较剩余数值，强行判一方失败，随后清掉其兵力、压低生命和技力，甚至进入俘虏结算。

新版与手动战场的时间到规则一致：**双方将领仍活着就是和局**，写回真实剩余生命、兵力和技力，不标记本次失败，也不凭和局产生俘虏或胜利经验。

- **玩家单次自动**：显示未分胜负，返回选将，保留双方剩余状态。
- **玩家全体自动**：遇到和局暂停本次连续结算，返回选将；可以重新选将继续战斗。不会重复模拟同一对将领直到强行分胜负。
- **电脑野战**：结束本次交战，双方退向友城。金钱与存活部队保留。
- **电脑攻城**：和局不算攻占，攻方退向友城，守城归属保留。

前面已经结束的对决及其真实俘虏继续按规则结算；若其中已俘获君主，原有势力灭亡规则仍会生效。原出发城已失守时寻找其他友城；完全没有退路时驻留，防止主动在原地反复触发同一场和局。获得新路线后恢复正常移动与遭遇。

## 强队也要看兵种、伤势与技能

本次没有修改普通攻击、三兵种克制与智力冷却数值。战斗仍考虑实际兵力、剩余生命和技力、技能、城防与随机过程。高武力不保证在所有兵种或连续作战条件下取胜。

自动结算仍是简化模拟，没有重现手动战场中的完整站位、移动、范围技能覆盖与玩家操作。验证范围与受控对战结果见[验证报告](VALIDATION-v1.4.1.md)。此前的[主动攻势、兵符减量和君主显示修复](GAMEPLAY-v1.4.0.md)继续保留。
