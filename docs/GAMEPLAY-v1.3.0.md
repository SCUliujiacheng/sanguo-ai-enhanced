## 只记住一个克制环

**弓箭兵 → 长枪兵 → 朴刀兵 → 弓箭兵**，箭头表示克制。

| 使用兵种 | 优势对手 | 劣势对手 |
| --- | --- | --- |
| 弓箭兵 | 长枪兵 | 朴刀兵 |
| 长枪兵 | 朴刀兵 | 弓箭兵 |
| 朴刀兵 | 弓箭兵 | 长枪兵 |

征兵和武将资料中只保留这三种。手动战斗与自动结算共用这一克制关系；兵力、武将状态、技能和守城条件仍影响结果，克制不能保证以少胜多。

玩家手动搜索、总内政搜索和电脑内政都只产出三种兵符。物品使用与自动分配按这三类判断是否已经学会，避免把旧兵种换个名字后仍重复消耗兵符。

旧存档读入时按以下规则转换：大刀兵、蛮族兵归入长枪兵；链锤兵、飞刀兵归入弓箭兵；武斗兵、铁锤兵、藤甲兵、黄巾贼归入朴刀兵。原有弓、枪、刀不变；已学兵种合并，库存兵符按相同规则转换。原来的骑兵升级层并入所属兵种，保留当前总兵力和容量，升级不再拆成两种人数。

## 升迁直接看技能

升迁的三个候选按钮直接显示选中后获得的武将技，确认对话也显示技能名；武将资料中的“职位”改为“技能”。升级门槛与原来的技能分支保持不变，不需要再记官职对应哪一招。

## 智力让技能转得更快

实战蓄技和自动战斗共用冷却规则。基础充能按武力、智力中较高者计算，智力超过 60 后再缩短冷却，每点减少 1%，最多减少 45%。

| 智力 | 额外冷却减免 |
| :---: | :---: |
| 60 及以下 | 0% |
| 80 | 20% |
| 90 | 30% |
| 100 | 40% |
| 105 及以上 | 45% |

这张表是在基础充能速度之上应用的减免。智力将因而更容易在战斗中多次施法，每次依旧消耗技能所需技力，玩家和电脑适用同样规则。

## 自动战斗看强弱，也看时机

- 统一兵种编号和克制判定，修正弓箭兵在旧模拟中攻击间隔被加倍的问题。
- 按当前血量、兵力、技力选择攻击、治疗、补兵或定身技能，满状态时不浪费治疗与补兵。
- 去掉固定左侧先手优势；全体自动换将会考虑伤势、兵力和兵种对位。
- 战损与技力消耗写回真实武将，连续作战会积累消耗。

自动战斗仍是快速数值模拟，范围技的覆盖采用估算，不承诺与玩家手动走位、施法时机产生完全相同的结果。

## 电脑会组织多队攻城

面对单队难以攻下的重镇，电脑可以从最多三个相邻友城组织协同进攻。每个出发城市保留守军，单队最多九名将领；不为凑十将而抽空城市。

计划会核对总战力、人数、留守安全与实际路线。抵达前重新核查真实在途后援；援军接近时可短暂等待，援军被拦、撤走或目标变化时重新判断。后续队伍能利用前一队造成的消耗尝试突破，仍会拒绝明显无望的单将冲城。

## 新时期旗帜

新增君主使用明确的旗帜映射，城市和行军部队保持一致。潼关风云中，马超用“马”字旗、曹操用“曹”字旗；各时期的势力旗帜均检查重复。
