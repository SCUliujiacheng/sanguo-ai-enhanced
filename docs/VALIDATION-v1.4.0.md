## 本次修复证据

- 旧版三条实际搜索路径会继续产生重复兵符；新版按 100 个分支随机值穷举，兵符均为 8 次，人才、装备和阵法分支保留。需求为零或库存够用时均停止重复产出。
- 原吕布旗帜映射误用 Flag19（贼）；新版绑定实际武将 28，头像资源 Head/Head029，旗帜 RulerFlag28。新图集覆盖 255 名武将、每人四帧，并核对原帧尺寸、裁切和坐标。
- 多月测试覆盖真实聚兵与派遣；五城各三名精锐的配置能组成两支五将队伍，普通实力不足的配置仍保留安全出兵限制。具体回合和配置以 JSON 报告为准。
- 金钱、将领归属和军队数量守恒，以及目标变更、增援容量和在途支持失效，均有行为回归。
