# 剧本与招募设计

本扩展在原有5个时期之外增加7个历史开局和2个架空挑战，沿用原作48城、255名角色、装备和地图。城池归属、驻军与资源是为原作地图设计的游戏化配置，不代表逐城逐日精确还原历史。

| 新增时期 | 开局定位 | 主要玩法变化 |
|---|---|---|
| 官渡争锋 · 200 | 官渡战争前夕，孙策尚在，刘备仍守徐州 | 袁绍纵深与曹操多线压力并存，徐州、江东可另选突破方向 |
| 三顾茅庐 · 207 | 刘备屯新野，诸葛亮已入队 | 一城十将，需要先选择有限资金投向防守、内政还是扩张 |
| 潼关风云 · 211 | 潼关战前，马超代表关西联军 | 关西与中原正面对阵，汉中、益州可趁隙发展 |
| 入主巴蜀 · 214 | 雒城战役前，庞统、张任仍在 | 刘备跨荆益分兵，集中进成都可能暴露荆州 |
| 汉中争夺 · 219 | 定军山前，夏侯渊尚守汉中 | 刘备北进同时需要留兵给关羽防守荆州 |
| 夷陵之战 · 222 | 夷陵决战前，曹丕、刘备、孙权并立 | 蜀吴前线集中于永安、江陵，魏方有机会从另一线施压 |
| 北伐中原 · 228 | 第一次北伐前，曹睿、刘禅、孙权，姜维仍在魏 | 蜀汉由汉中进关陇，魏须调配纵深守军，吴可进江淮 |
| 英雄集结 · 架空 | 九家各五城，历代名将同台 | 城数与经济起点相同，人物实力不同，多方向争夺中立城市 |
| 孤城逆袭 · 架空 | 推荐刘备：新野一城十将 | 强敌环伺，有启动资金、预备兵和上庸等中立扩张方向 |

各剧本改变开局状态；没有新增固定战役事件、自动倒戈、外交系统或特殊胜利条件，目标仍是统一。历史时期取战役前的年初快照，因此219年的夏侯渊、222年的马超与马良仍可在场。

## 历史搜索规则

历史模式中的在野人才，需要同时满足当前年份、效力阵营和活动地区。历史所属势力全部灭亡后，指定地区的当前占领者可以招募；年份与地区条件仍有效。已加入、被俘以及原存档内的人物不被自动迁移或按史实强制死亡。

例如诸葛亮从207年起在刘备所属的荆州地区进入搜索范围。黄忠早年在刘表的长沙范围，刘备平定荆南后属于刘备阶段；魏延采用随刘备入蜀的记载，不采用演义中先仕韩玄的经历。年内转投只用整数年表达：228年按北伐前快照将姜维列为魏方，229年起调整其在野搜索阶段。已招募的姜维不受此切换影响。依据分别见[《三国志》卷三十五](https://zh.wikisource.org/wiki/三國志/卷35)、[卷三十六](https://zh.wikisource.org/wiki/三國志/卷36)、[卷四十](https://zh.wikisource.org/wiki/三國志/卷40)、[卷四十四](https://zh.wikisource.org/wiki/三國志/卷44)。

规则覆盖原有255名角色，但证据精度不同：重点人物按史料时序校正，其他条目明确标记为“剧本推定”或“保守推定”。原史料没有首次效力年份的，不将游戏中的起始年冒称为确切初仕年。未知卒年条目有明确标注的游戏截止；不是完整人物年表。貂蝉、祝融夫人、兀突骨等演义身份不进入历史随机搜人池，原本已经在场的人物保持原状，两个架空剧本可自由搜索全人物。

史料与原图不完全对应：原库缺少韩遂、张绣、韩玄等人，关西用马超代表；张绣、韩玄的搜索阶段按当地占领者承接。相应规则在JSON的`note`中注明。

## 配置与生成

- `06-*.json`至`14-*.json`：新增剧本的君主、城池、将领、前线驻军与资源。
- `historical_recruitment.json`：255名角色的阶段规则、证据类型、说明与史料链接。
- `roster_bounds.json`：新增开局的角色可用边界；部分为保守选角边界，不是严格生卒年表。

生成器仅依赖Python标准库；需要使用者在本地准备匹配版本的基准XML和姓名映射。仓库不包含提取的原版场景XML或整套反编译源码。

```text
python scripts/generate_scenarios.py --base-dir local/base --output-dir local/generated
python scripts/generate_recruitment.py --output local/generated/HistoricalRecruitment.xml
python -m unittest discover -s scripts -p test_data.py -v
```

生成器检查48城、255将、每城最多10将、同阵营驻军、每位君主在自己的城内、合法兵力和装备数值、角色出场边界、搜索阶段不重叠。没有本地基准文件时，只运行不依赖原游戏数据的招募规则测试。

官渡与潼关的大致时序参考[《三国志》卷一](https://zh.wikisource.org/wiki/三國志/卷01)，入蜀与汉中参考[卷三十二](https://zh.wikisource.org/wiki/三國志/卷32)，夷陵参考[卷五十八](https://zh.wikisource.org/wiki/三國志/卷58)。逐将适用来源记录在招募JSON中。
